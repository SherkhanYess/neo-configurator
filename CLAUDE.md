# Neo Diamond — каталог

## Перед вёрсткой

Читать [DESIGN.md](DESIGN.md) — утверждённая лента, правило цветов под фото и запреты.
Без него выбирается самое среднее и сайт выходит похожим на шаблон.

## Где что живёт

- Каталог — `src/catalog/`. Конструктор на корневом пути — `src/configurator/`,
  **его не трогать**.
- Сборка: `npm run build` = `vite build && node scripts/prerender.mjs`.
  Prerender пишет по странице на товар, OG-превью и правила маршрутизации.
- `IS_SANDBOX=1` закрывает сборку от индексации и не публикует карту сайта,
  `llms.txt` и машинный каталог.

## Проверка

- `npm test` — восемь наборов. Новое клиентское событие обязано быть в белом
  списке `netlify/functions/track.js` и агрегироваться в `stats.js`, иначе
  тест падает.
- Экран считается готовым после скриншота на 390 px, а не после успешной
  сборки.

## Гиды

`/catalog/guides/:slug` — статьи для мужчин, `src/catalog/guides/`. Новый гид:
запись в `data/guides.js`, файл с текстом в `guides/` и строка в `BODIES`
(`screens/GuideScreen.jsx`). Подробности — DESIGN.md, «Гиды».

## Админка

`/catalog/admin` — `src/studio/`. Фото, тексты и порядок ленты, отзывы,
намёки, цены. Сайт берёт это с сервера (`/api/content`, `/api/media`), а
не из кода. Подробности — DESIGN.md, «Админка».

Локально: `npx netlify dev` — пароль берётся из `.env.development.local`
(`ADMIN_TOKEN=…`, файл не в гите).

## Новые фото ленты

Обычно — через админку: цвет подберётся сам. Файлы в `public/assets/feed/`
тоже работают: после них `npm run feed:tones`.
