# Neo Diamond — каталог

## Перед вёрсткой

Читать [DESIGN.md](DESIGN.md) — направление, палитра, шкалы и список запретов.
Без него выбирается самое среднее и сайт выходит похожим на шаблон.

## Где что живёт

- Каталог — `src/catalog/`. Конструктор на корневом пути — `src/configurator/`,
  **его не трогать**.
- Сборка: `npm run build` = `vite build && node scripts/prerender.mjs`.
  Prerender пишет по странице на товар, OG-превью и правила маршрутизации.
- `IS_SANDBOX=1` закрывает сборку от индексации и не публикует карту сайта,
  `llms.txt` и машинный каталог.

## Проверка

- `npm test` — семь наборов. Новое клиентское событие обязано быть в белом
  списке `netlify/functions/track.js` и агрегироваться в `stats.js`, иначе
  тест падает.
- Экран считается готовым после скриншота на 390 px, а не после успешной
  сборки.
